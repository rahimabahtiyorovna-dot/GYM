# GYM- Fitness & Gym Website

A modern, responsive fitness gym landing page designed for training enthusiasts. It features an engaging hero section, professional trainers, class schedules, a photo gallery, and an interactive contact form to help users easily connect with the gym. 🏋️‍♂️💪

## ✨ Features
* **Hero Section:** High-energy layout with an inspiring introductory title.
* **About Us:** Overview of professional training programs for building a strong physique.
* **Trainers:** Showcase of expert gym trainers and coaches.
* **Gallery:** Visual showcase of workout environments and fitness sessions (Strength, Cardio, Energy).
* **Benefits:** Highlight of flexible schedules, energetic atmosphere, and effective exercises.
* **Contact Form:** Fully structured form for user messages and inquiries.

## 🛠️ Technologies Used
* **HTML5** – Page structure and semantics
* **CSS3** – Styling, modern layouts, and responsiveness
* **JavaScript** – Interactive UI elements
